# 投球テストシーン

`Assets/Scenes/PitchTest.unity`を開き、Playで実行する。
左上のリストには、シーンの`PitchTestSceneController > Pitch Types`に登録した球種が表示される。
初期状態は**コース指定**。クリックした通過点へ向けて投球方向を計算する。

登録済みの球種は基本球種21件。球種を追加した場合はシーンの`Pitch Types`へ登録する。
1m=1.2Unity単位、人物約1.80m、ボール直径7.32cm、ゾーン幅43.18cmの環境で確認している。
球速・回転数はkm/h・rpmの実単位なので、人物や球場の縮尺を理由に倍率を掛けない。

## 方向指定で物理を確認する

待機中に`T`を押すと**方向指定**へ切り替わる。Solverを使わず、設定した角度と球速で投げる。
初期角度は左右0度・仰角0度（ワールド+Z方向）。クリック、Space、再投球ボタンで投球を始める。

- `I / K`: 仰角を0.1度ずつ上げる・下げる。
- `J / L`: 左右角を0.1度ずつ-X側・+X側へ変更する。
- Inspectorの`Launch Angles Degrees`: Xが左右角、Yが仰角。回転軸とは別の設定。
- 黄色の点は比較する基準点。方向指定では、その点へ狙い直さない。
- 同じ角度で球種だけを変えると、球速と回転による軌道の違いを確認できる。

投球は既存アニメーションの`ReleasedBall`イベントで開始する。
リリース位置は、その時点の手の位置を使う。

## コース指定

起動時は**コース指定**。方向指定から戻す場合は、待機中に`T`を押す。
マウスでストライクゾーン上の通過点を決め、クリックして投球する。
真横・真上のカメラでは右側の2Dパネルを使う。

Solverは球速・総回転数・ワールド回転軸を固定したまま、投げ出す方向を探す。
ボールを放した後は、方向指定と同じ物理計算を使う。
`T`で方向指定とコース指定を切り替えられる。

## 共通操作

| 操作 | 動作 |
| --- | --- |
| 左上の球種リスト | 投げる球種を選択 |
| Space / 再投球 | 同じ設定で、選択中の球種を投球 |
| R / リセット | 投球を中断して待機姿勢へ戻す |
| 矢印キー | 8か所のカメラを切り替える |
| F | 接近・横のカメラへ切り替える |
| 再生速度 | アニメーションとボールの再生速度を変更。計算結果は変わらない |
| 軌道を表示 | 選択した球の軌道を表示 |
| 無回転との比較を表示 | 同じ初速の無回転球を青線で表示 |

投球中の球種・方式・角度変更はキー操作では受け付けない。
球種リストやボタンの操作を、ワールドへの投球クリックとして扱わない。

## 表示と比較

- 水色: カーソル、黄色: 指定点／基準点、桃色: 実際のZ平面通過点。
- 黄線: 選択した球。青線: 同じ位置・同じ速度ベクトルから放した無回転球。
- 両方に重力・空気抵抗を計算する。青線を目標へ狙い直す処理はない。
- 左下の差は同じZ平面で比較する。+Xを右、-Xを左と表記する。捕手側カメラの画面上では左右が逆になる。
- 方向指定で表示する「基準点との差」はSolverの誤差ではない。
- 方向指定でZ平面に届かなかった場合も計算済みの軌道を表示する。

共通の`BallPhysicsCalculator`、`BallTrajectorySimulator`を使用する。
投球の積分はRK4、既定のサンプル間隔は0.01秒。回転表示にも同じ`SpinState`を渡す。

球種は`Create > Baseball > Pitch Type`で作成できる。
球速（km/h）、総回転数（rpm）、3D回転軸を設定し、シーンの`Pitch Types`へ登録する。
回転軸の設定例ボタンは+Zへ投げる場合のもの。回転効率・ジャイロ成分は軸と速度から計算する参考表示であり、入力項目ではない。
