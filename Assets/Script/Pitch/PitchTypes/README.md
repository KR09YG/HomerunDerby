# 基本球種の回転設定

このフォルダー直下の21球種は、+Z方向へ投げる右投手用の基本設定です。球速と総回転数は従来の参考値を維持し、3D回転軸だけを球種の特徴から推定し直しました。各アセットの参考選手と資料は球速・総回転数の出所として残しています。回転軸はその選手の測定値ではなく、実在選手の軌道への一致も主張しません。選手別フォルダーの設定は変更していません。

## 軸の決め方

ワールド座標では、+Zが捕手方向、+Xが右投手の腕側、+Yが上です。リリース時にほぼ+Zへ飛ぶ球では、回転軸の-X成分が上向きの揚力、+X成分が下向きの力、+Y成分が腕側、-Y成分がグラブ側の力を作ります。残る-Z成分は右投手の通常のジャイロ方向という仮定です。右投手でも逆方向のジャイロはあり得るので、個々の選手を再現するときには別に確認します。

軸は単位ベクトルとして保存しています。以下の「直交割合」は+Z方向の初速を基準にした `sqrt(axis.x² + axis.y²)` です。回転による力は飛翔中の速度に直交する軸成分から毎回計算されるため、この割合は飛翔中ずっと一定とは限りません。速度に合わせて軸そのものを回す処理はしていません。

| 球種 | 直交割合 | 推定した回転の特徴 |
| --- | ---: | --- |
| ストレート | 72% | バックスピン主体、少し腕側 |
| ツーシーム | 65% | 直球より低い揚力、腕側 |
| カット | 34% | バックスピンを残し、小さくグラブ側 |
| スライダー | 14% | ジャイロ主体、小さくグラブ側 |
| 高速スライダー | 12% | ジャイロ主体、高速で小さくグラブ側 |
| スイーパー | 36% | スライダーより強い横回転、グラブ側 |
| 縦スライダー | 30% | トップスピン主体、下方向 |
| カーブ | 56% | トップスピン主体、下とグラブ側 |
| ナックルカーブ | 56% | カーブに近い回転方向 |
| パワーカーブ | 55% | 強いトップスピン、下とグラブ側 |
| スローカーブ | 56% | 低速、下とグラブ側 |
| スラーブ | 55% | 横と下の中間的な変化 |
| チェンジアップ | 68% | 低速、腕側 |
| サークルチェンジ | 70% | 低速、腕側の成分がやや多い |
| シンカー | 48% | 腕側、直球より低い揚力 |
| シュート | 72% | 腕側の横変化とバックスピン |
| スプリット | 20% | 低回転、重力による落下が中心 |
| フォーク | 25% | 低回転、小さなトップスピン |
| パーム | 30% | 低回転、低い揚力 |
| イーファス | 20% | 低速・低回転、わずかなトップスピン |
| ナックル | 0% | 低回転のみ。縫い目による不規則な動きは未実装 |

これらは物理モデルへの入力例であり、公開のActive Spin %をそのまま設定した値ではありません。公開Active Spinは軌道から推定される場合があり、実測の3D軸と同一視できません。スイーパーの横変化にも、実際は縫い目の影響が含まれる場合があります。この設定では追加の縫い目力を使っていません。

## 確認方法と限界

`Artifacts/BasicPitchAxisAudit/validation.csv` に、各球種を同じ条件で投げた場合の無回転球との差を保存しています。条件はリリース高さ1.8m、水平に+Zへ発射、捕手まで18.44m、空気密度1.225kg/m³、RK4の時間刻み0.001秒です。投球方向を探すSolver、地面との衝突、カメラは使っていません。遅い球ではこの水平発射条件のまま捕手まで飛ばせないため、表の値は空力だけを比較するための数値です。ストレートは上向き約55cm、スライダーはグラブ側約20cm、スイーパーはグラブ側約45cm、カーブは下向き約52cmでした。この値は各球種の推定軸に対するモデルの出力であり、特定選手の実測変化量ではありません。

試合ではSolverが同じ通過点に向かう初速方向を選びます。このため、画面上の通過点の差だけでは球種の曲がりを比較できません。曲がり方を見る際は、同じ初速方向からの全軌道、または同じ球速の無回転球との差を比較してください。
